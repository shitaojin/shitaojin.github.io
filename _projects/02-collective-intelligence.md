This theme positions architectural programming as a collaborative intelligence problem. Instead of treating a design brief
as a fixed document, the research studies how stakeholders, experts, public values, project constraints, and AI agents can
jointly define objectives and search for better early-stage decisions in complex public projects.

The intellectual starting point is that megaproject programming is both a design problem and a governance problem. The
brief must coordinate functional requirements, spatial performance, construction feasibility, public value, risk
exposure, and long-term operation. My work therefore connects architectural programming theory with collective
intelligence, group decision-making, and multi-agent reinforcement learning.

## Research Content

The research begins with the comparative and interdisciplinary mapping of architectural programming, clarifying how the
field has evolved from user needs analysis and facility planning toward value management, stakeholder coordination, and
computational decision support. This provides the theoretical base for treating architectural programming as a structured
process of problem seeking, evidence gathering, requirement definition, and performance negotiation.

Building on this base, I developed a group decision-making model for architectural programming in megaprojects. The model
uses stakeholder participation and programming dimensions to clarify how different actors evaluate requirements and how
conflicting priorities can be aggregated into defensible decisions. This work is extended through collective-intelligence
research in construction, which identifies how participatory crowdsourcing, multi-agent systems, digital twins, and
data-driven platforms can help the construction sector coordinate distributed knowledge.

The current doctoral direction advances this work into multi-agent reinforcement learning. Each agent represents a
decision participant or programming objective, and the system learns how to negotiate among competing requirements under
project constraints. The long-term goal is an AI-assisted architectural programming platform for mega transportation hubs
that can support transparent preference learning, scenario testing, and adaptive optimization before design decisions
become costly to change.

## Outcomes

This theme creates a coherent bridge between architectural programming theory and intelligent decision support. It also
defines a postdoctoral research direction around AI-supported briefing platforms for public buildings, transport hubs,
and social infrastructure.
